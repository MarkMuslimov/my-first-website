SCHACH


Was ist Schach?

  • Schach (Schach König übersetzt) ist eine strategsiches Brettspiel.
  • Dabei bewegen zwei Spieler Figuren auf dem Brett abwechselnd ab.
  • Das Ziel ist es den gegnerischen König so anzugreifen, dass
    der Gegner keinen Zug hat um den Angrif zu verteidigen.

Wie wird man gut in Schach?

  • Im Schach gibt es Punkte namens ELO.
  • Je mehr Punkte, desto besser ist man bzw. forder bessere Gegner heraus.
  • Das absolute kleinste ELO beträgt 100ELO, das höchste ELO ist ~3.300+

  1. Spielen Sie mehr Schach
  2. Lesen Sie Schach-Bücher bzw. konsumieren Sie Schach-Theorie
  3. Analysieren Sie ihre Spiele
